# Строение атома

Интерактивный урок для 8–9 класса: 3D-модель атома, по нажатию на протон, нейтрон или электрон показывается, что это за частица и за что она отвечает. Есть элементы с 1 по 20, ионы и изотопы, история моделей атома и тест.

Сайт: https://fed12113-ship-it.github.io/atom/

Всё в одном файле `index.html`: стили, скрипты и шрифты встроены, внешних запросов нет.
